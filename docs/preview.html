Tối ưu Độ trễ Hệ thống & Phân phối Bộ nhớ Đệm Toàn cầu

Làm thế nào để giảm thời gian phản hồi từ 300ms xuống còn 15ms bằng cách kết hợp Edge CDN, thuật toán Cache Invalidation và toán học xác suất Zipf?

1. Triển khai Worker tại biên mạng (Edge Worker)

Mỗi yêu cầu từ trình duyệt được chặn lại ngay tại trạm PoP gần nhất (Hà Nội hoặc TP.HCM) để giải mã header trước khi quyết định gọi cơ sở dữ liệu gốc:

edge-cache.ts
export default {
async fetch(request: Request, env: Env): Promise<Response> {
// Check Edge Key-Value Cache
const cacheKey = `page:${new URL(request.url).pathname}`;
return await env.CACHE.get(cacheKey) || fetch(request);
}
}

2. Mô hình Toán học: Tỷ lệ Cache Hit theo định luật Zipf

Xác suất truy cập vào tài nguyên thứ $k$ tuân theo phân phối hàm mũ, trong đó $\alpha$ đại diện cho mức độ tập trung bài viết:

$$P(k) = \frac{k^{-\alpha}}{\sum_{n=1}^{N} n^{-\alpha}} \quad \text{với } \alpha \in [0.8, 1.2]$$
